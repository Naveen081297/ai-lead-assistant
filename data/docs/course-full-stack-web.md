# Full Stack Web Development

Build and deploy production web applications with JavaScript in 32 weeks.

## Who it is for

Graduates and final-year students who want to become software developers. Basic computer literacy is expected. Learners must pass the aptitude test.

## Format and schedule

- Duration: 32 weeks (about 8 months)
- Schedule: weekday evenings, Monday, Wednesday and Friday, 7:00 PM to 9:30 PM IST
- Mode: live online, or classroom at the Pune campus or the Bengaluru centre
- Effort: 7.5 hours of live class plus 8 to 10 hours of practice per week

## Curriculum

1. Web fundamentals: HTML, CSS, responsive design, Git (weeks 1-5)
2. JavaScript in depth, including async programming (weeks 6-11)
3. React and front-end state management (weeks 12-17)
4. Node.js, Express and REST APIs (weeks 18-22)
5. MongoDB and PostgreSQL (weeks 23-26)
6. Testing, Docker and cloud deployment (weeks 27-29)
7. Team capstone: build and ship a full application (weeks 30-32)

## Hardware

Because of local development servers and Docker, a laptop with 16 GB RAM is strongly recommended for this program.
