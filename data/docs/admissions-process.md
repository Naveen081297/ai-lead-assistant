# Admissions Process

## Eligibility

| Program | Minimum eligibility | Entry check |
|---|---|---|
| Data Analytics Pro | Graduate or final-year undergraduate | Aptitude test |
| Full Stack Web Development | Graduate or final-year undergraduate | Aptitude test |
| UI/UX Design Professional | Graduate or final-year undergraduate | Design exercise |
| Digital Marketing Accelerator | Class 12 pass, aged 18 or over | None |
| Python Foundations | Aged 16 or over | None |

## Steps

1. **Apply online** on the website, or ask an admissions counsellor to start the form for you.
2. **Counselling call** (about 20 minutes) to check that the program fits your goals.
3. **Entry check** where required: aptitude test or design exercise.
4. **Offer** by email within 3 working days of the entry check.
5. **Reserve your seat** by paying the INR 5,000 registration fee within 7 days of the offer.
6. **Submit documents** and pay the first instalment or full fee before the batch starts.

## Aptitude test

A 30-minute online test with 25 multiple-choice questions on logical reasoning, basic maths and English comprehension. No programming knowledge is needed. The pass mark is 60%. You can retake it once after 14 days.

## Documents required

- Government photo ID (Aadhaar, passport, PAN or driving licence)
- Latest degree certificate or marksheet (final-year students: latest semester marksheet)
- One passport-size photograph (digital)

## Application deadline

Applications close 10 days before each batch start date, or earlier if the batch is full.
