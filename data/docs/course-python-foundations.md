# Python Foundations

A beginner course for people who have never programmed before.

## Who it is for

Complete beginners aged 16 or over. There are no prerequisites and no aptitude test. Many learners take it before applying to Data Analytics Pro or Full Stack Web Development.

## Format and schedule

- Duration: 8 weeks
- Mode: self-paced video lessons on the Brightwater Learn platform, with a weekly live doubt-clearing session every Thursday, 8:00 PM to 9:00 PM IST
- Start date: rolling enrolment. You can start any day.
- Access: course materials stay available for 12 months from enrolment

## Curriculum

1. Variables, data types and operators
2. Conditions and loops
3. Functions and modules
4. Lists, dictionaries and other data structures
5. Files and error handling
6. Intro to object-oriented programming
7. Mini project: a command-line expense tracker

## Fee

INR 18,500 plus 18% GST. Payable in full at enrolment (no instalments for this course).

## Upgrade credit

If you enrol in Data Analytics Pro or Full Stack Web Development within 6 months of finishing Python Foundations, INR 5,000 of the Python Foundations fee is credited against the new course fee.
